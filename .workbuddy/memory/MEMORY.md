## 一、项目是什么

- **LabPulse**：桌面网页应用（Python + Streamlit，本地跑，不上云、无账号）。
  职责 = 把湿实验的 **SOP 操作时间线**与**生理信号**放在同一条时间轴上，
  **在操作者还在干活的时候**发现"偏离他本人基线的状态异常"，并定位到具体 SOP 步骤。
- **一句定位**：**它是镜子，不是判官。** 系统不判断你能不能继续干，只把你自己的信号
  对着你自己的基线摆出来，由你决定。
  > 我们很难定义"累"，但能帮一个人察觉自己累了。
- **两通道，故意不对称**（2026-10-12 **第二次**修订后的最终分工）：

  | 通道 | 测什么 | 角色 |
  |---|---|---|
  | **脑电 EEG** | 认知负荷 / 注意 | **主** |
  | **表面肌电 EMG** | 动作执行 + **肌肉疲劳**（MDF 随持续收缩下降） | **辅**（推迟到 Stage 4 前后；届时按"探索性"报告） |

  为什么主通道是脑电（这是被推翻过一次的取舍，理由要记住）：
  1. **风险不能压在主通道上**——那个技术风险（肌电双极 vs 脑电单端能否同采）现在**连辅通道都不卡了**：
     10-11 已查清同采在芯片层可行（SRB2 每通道独立），只剩约 10 分钟两板实测；
     10-13 又决定肌电整体推迟到 Stage 4。主目标只走脑电。
     ⚠️ 但**脑电设备的验收结论截至 10-13 还没见记录**（见 §四、`EEG\SHARED_DEPS.md` §6.4）
  2. **验证证据更硬**——白噪声是**实验者人为开关**的负荷，我们确知它发生了；
     时疲劳是自然发生、幅度不可控的。
  3. **领域与设备一致性**——主题、空间、硬件都在脑电上，主目标不该锚在辅助模态上。

  注意：脑电**没有金标准**。能成立的逻辑不是"测出来的值对"，而是
  **"同一个人的两段能不能分开"**——靠人为开关负荷，而不是靠一把标准尺。
- **SOP 步骤表是骨架**：不是从信号反推时间线，而是用 SOP 提供时间线。
  输出不是抽象的"异常片段"，而是 **"稀释第 3 步偏离"** 这种可解释的命名结论。
  步骤表做成**配置文件**（称量 / 稀释 / 采样各一份），一套代码服务三个任务。
- **"状态异常"的操作化定义**（必须在采数据前定死）：
  > 某通道指标相对该操作者**安静作业基线**偏离超过 **X 倍标准差**，且持续 ≥ **Y 秒**。

  - **脑电（主）**：**theta / alpha 功率比**为主指标；其余频段分别报告。**不合成复合指数。**
  - **肌电（辅）**：**MDF** + **RMS**。
  - 两通道**各自判定、分别报告，永不融合成一个分数**。
  - ⚠️ 主指标是**双侧**的：白噪声（唤醒升高）和警觉度衰减会把 theta/alpha 推向**相反方向**
    → 这正是"不许把偏离翻译成命名状态"的实验依据。
  - X / Y 在头两次基线 session 分析后**按通道**冻结。

## 三、被试与协议（3 人，固定分工）

| 操作者 | 任务 |
|---|---|
| A | 称量 |
| B（用户本人） | 稀释 |
| C | 采样 |

- 每人**只做自己那一项，不交叉** → 人与任务绑死，**不作任何跨人 / 跨任务的比较结论**。
  三个人 = 三个独立的被试内小实验，各建各的基线。
- **两个对照**：

  1. **白噪声段 → 验证主通道（脑电）。** 固定噪声源、固定音量、同一套硬件。
     若同一操作者内安静段与噪声段都分不开，这条通道就没在测可用的东西。
     *不用音乐*：节奏会进脑电频谱，污染正要测的那个频段。
  2. **同 session 前 30 min vs 后 30 min → 主通道的第二个对照。**
     （原来还兼验肌电 MDF——肌电推迟后那半属 Stage 4，本阶段不做。）
     零额外 session。两个对照**方向相反**（外源突加 vs 内源缓慢衰减），
     单个通过只算弱证据，两个都能分开才算通道在工作。

- 可选校准：每 session 首尾各一次 20–30 s 等长保持（约 1 分钟），给 MDF 一个任务无关的
  **相对**参照。做不做，基线看完再定。
- 每 session 固定 90 分钟、实际 1–2 小时；**本来就落在每周真实排班里，不额外排期**。
- 数据量：12 次 session ≈ 18 小时 ≈ **~2000 个 30 秒窗口**。
  ⚠️ 相邻窗口强相关，**真正的约束是 session 数，不是窗口数**。

## 八、明确不做（写进提案第 6 节，别越界）

- **不做自动决策**：系统不说"停"，不拦操作
- **不主张"检测异常能减少错误"**——那需要"有反馈 vs 无反馈"的对照，本研究范围外
- **不人为制造错误**（真实试剂属于进行中的项目）
- **不做跨人 / 跨任务比较**
- **不做状态分类**（不输出"疲劳 / 过载"这类命名状态），只输出定位到步骤的异常标记
- **不合成单一"状态分数"**（脑电与肌电分开报）
- 不做医疗 / 诊断主张；多用户账号、云部署、手机端不做

## 一、问题

湿实验的质量保障**完全是事后发现**。稀释倍数算错、离心管标错，通常要到下游才暴露——几小时之后，或者永远不暴露。等失效显形时，原因已经不可恢复：没人知道是哪一步出的问题，更不知道为什么会出。

现有流程缺两样东西：

1. **错误发现得太晚。** 一批样品报废时，真正出问题的那一步已经埋在两小时的时间线里，没有任何标记。
2. **操作者的状态从未被记录。** 人因研究普遍把认知过载和注意力衰退当作流程性作业的主要错误来源，但在真实实验室里，操作者的状态**没有任何东西在记录**。自陈不准，而且一打断就把手上的活毁了；录像回看准，但没人会为了找五秒钟的失误去回看两小时素材。

难点在于：这个状态**没有阈值，也没有金标准**，让操作者自己报告又会破坏作业节奏。所以我们不去测量它，而是换一个能验证的问法（第二节）。

实际后果：一个正在走向失误的操作者，在失误真正发生之前，收不到任何信号。

## 二、研究方向

**LabPulse 是一面镜子，不是一个判官。** 系统不替操作者判断他还能不能继续；它把操作者自己的信号对着他自己的基线摆出来看，判断权在操作者手里。整件事的前提就是这句话：*我们很难定义「累不累」，但可以帮一个人意识到自己累了。*

我们不去定义、也不去测量「疲劳」这个复合概念，只问一个更窄、也答得出来的问题：

> **一个人的生理指标相对他自己基线的偏离——「状态异常」——能不能在他还在工作时就被识别出来，并且定位到 SOP 的某一步？**

**验证逻辑：不跟绝对刻度比，跟自己前后比。** 认知负荷没有一把能直接读数的尺子，但**我们可以自己把负荷打开和关掉**——于是验证问题从「测出来的值对不对」变成「同一个人的两段能不能分开」，后者答得出来。

**通道分工：脑电为主先做，肌电后加。**

| 通道 | 测什么 | 强在哪 | 角色 |
|---|---|---|---|
| **脑电 EEG** | 认知负荷 / 注意 | 本项目真正想测的状态就在这条通道上，而且**负荷可以被实验者人为开关**（白噪声段），所以「它有没有在测东西」是可验证的，不必依赖并不存在的金标准。弱点真实：真实作业中伪迹重（第八节）。 | **主（MVP 只做这条）** |
| **肌电 EMG**（表面） | 动作执行 + 肌肉疲劳 | 有教科书级标记：表面肌电**中值频率（MDF）随持续收缩而下降**，可测可重复，**单受试者就能看趋势**。 | **辅（后续阶段引入）** |

推迟肌电的理由有两条：① 主通道的验证**不依赖它**，早做不加分；② **同采已经不是拦路虎**——芯片层已查清：单端脑电与双端肌电可以同机同时采（依据见 `EEG\SHARED_DEPS.md` §6.2），只剩一个约 10 分钟的两块板叠加实测没做。把它排进 MVP，只会让工期卡在一个与主目标无关的工程步骤上。**代价**：Stage 3 只有单通道证据，跨模态互补性要到 Beta 才可能拿到；届时条件不成立就如实报为**单模态研究**。

**SOP 定骨架。** 不从信号里反推时间线，而让 SOP 步骤表直接提供时间线：每个信号窗口都挂在已知的一步上（「稀释，第 3 步」）。于是检测器的输出不是抽象的「一段异常」，而是一句**有名字、看得懂的话——「稀释 SOP 第 3 步偏离了」**。这是问题可解、结果也能向操作者解释的原因。

**主目标**：被试内识别状态异常——对每个人自己的基线比较，并定位到 SOP 时间线上。

**次级目标（仅探索性）**：观察「检出异常之后跟着发生了一次可记录的操作失误」的案例。自发错误太少，这只作为**产生假设的观察**，不是因果结论（第六节）。

**「状态异常」的操作定义**（采集开始前定死，检测器才可被评判）：

> 某条通道的指标，相对该操作者**安静作业基线**偏离超过 **X 个标准差**，并持续至少 **Y 秒**。
>
> - **脑电（主）**：**theta / alpha 功率比**为主指标；其余频段（delta / alpha / beta）相对本人基线的偏离**分别报告**，不合成复合指数——每引一个复合指数就多一层待验证假设。
> - **肌电（辅，后续阶段）**：任务所动用肌群的**中值频率（MDF）**与**幅值（RMS）**。
>
> 各通道**独立判定、分别报告，绝不融合成一个分数**（时间常数与证据强度都不同）。
>
> ⚠️ 主指标是**双侧**的：白噪声段（唤醒升高）与 session 后段（警觉度衰减）会把 theta/alpha **推向相反方向**。这恰恰是「不许把偏离翻译成命名状态」的实验依据（第六节）——同一个比值能朝两头偏，它就不是一个「累」的刻度。
>
> *X 与 Y 按通道在头两次基线 session 分析后定下，此后全程冻结。要求「持续」是为了不让一次眨眼或一个动作伪迹就报警。*

## 三、我们要做的东西：LabPulse

桌面 Web 应用（Python + Streamlit，本地运行，不上云，不要账号），存在的意义就是让上面这个研究做得成。五个模块：

| # | 模块 | 做什么 |
|---|---|---|
| 1 | **采集** | 读入已录制的脑电记录，建立统一时钟与通道映射。**MVP 只做脑电**；实时接收与肌电输入都在后续阶段。 |
| 2 | **SOP 时间线** | 按步骤表记录流程。这张表是**整个系统的骨架**——它把一段信号变成「有位置的结果」。步骤表用**配置文件**，每个任务一份（称量 / 稀释 / 采样），同一套代码服务三个任务。 |
| 3 | **事件标记** | 作业中一键 / 热键打标（「本步完成」、「发现失误」、自由标签）。稀释时双手都占着，任何需要打字的交互事实上不会发生。 |
| 4 | **状态异常检测** | 算**脑电 theta/alpha 比**，与本人基线比较，按冻结的 X / Y 规则标记持续偏离，并**归因到具体的 SOP 步骤**。肌电在后续阶段作为**第二条独立通道**加入。 |
| 5 | **同步回看与导出** | SOP 步骤时间线 × 生理曲线同图；点任一标记跳到对应信号区间；导出结构化 CSV。 |

信号质量检查**复用设备验收阶段已写好并验证过的分析内核**，不重写。

**对齐要求。** SOP 时间线由人打点（分钟量级），生理信号是连续的（毫秒量级）。两者必须打在同一时钟上；**错位必须小于 1 秒**，否则事后两条流根本对不上。

## 四、研究设计

**参与者与任务——固定分配。**

| 操作者 | 任务 | 时段 |
|---|---|---|
| 操作者 A | 称量 | 各自独立时段 |
| 操作者 B（本人） | 稀释 | 各自独立时段 |
| 操作者 C | 采样 | 各自独立时段 |

每人**只做自己那一项任务**，不交叉。这意味着人与任务无法分离，因此**不做任何跨人或跨任务的比较**（第六节）。每个人当作一个独立被试内案例：三个各自独立的小实验，各带自己的基线。

**对照 1 —— 白噪声 → 验证主通道。** 白噪声在固定区段打开：叠加外源负荷，不改变任务本身，而且**由实验者开关**，我们确知它发生了。如果脑电通道**在同一个操作者身上**都分不出安静段和噪声段，那它就没在测量任何可用的东西。噪声源、音量、硬件每次固定。（否掉音乐：节奏会进入脑电频谱，污染正要测的频段。）

**对照 2 —— session 内时间负荷 → 主通道的第二个对照。** session 固定 90 分钟，比较**前 30 分钟与后 30 分钟**；持续作业下的警觉度衰减是脑电最经典的效应之一。不额外花 session，负荷由真实工作本身产生。

因此主通道有**两个来源不同、方向相反**的对照：外源突加（白噪声）与内源缓降（时作业）。任一个单独通过只算弱证据，两个都能分开才算这条通道确实在工作。

**协议与数据量。**

| 阶段 | 每人 session 数 | 合计 | 日历 |
|---|---|---|---|
| 安静基线 | 2 | 6 | 2 周 |
| 白噪声段 | 2 | 6 | 2 周 |
| **合计** | **4** | **12 次 session** | **4 周** |

每次 session 1–2 小时，直接嵌入三位操作者**既有的每周实验日程**，不需要额外造 session。预计约 18 小时记录 ≈ **约 2000 个不重叠的 30 秒窗口**；相邻窗口强相关，有效独立样本远小于此，**瓶颈是 session 次数而不是窗口数**。

**次级（探索性）分析。** 失误当场记录，或事后由下游结果回填。自发错误率约每次 session 1–2 次，整个研究最多几十个事件，远低于做「状态↔错误」关联检验所需，因此只作为**案例集**报告。

## 五、成功标准

| # | 标准 | 目标 | 验证时间 |
|---|---|---|---|
| S1 | 每位操作者两次基线 session 完成并分析 | 3/3 人 | 第 2 周 |
| S2 | X / Y 阈值**按通道**定下并记录在案（白噪声段之前） | 冻结、成文 | 第 2 周 |
| S3 | **主通道**：白噪声段相对该操作者安静基线出现可检出偏移 | 3/3 人 | 第 4 周 |
| S4 | **主通道第二对照**：session 内前 30 分钟 vs 后 30 分钟，theta/alpha 出现可检出变化 | 12/12 次 session 算出；≥2/3 人 | 第 4 周 |
| S5 | SOP 标记与信号时间线对齐 | 错位 < 1 秒 | 第 1 周 |
| S6 | 一次完整 session（采集 → 打标 → 回看 → 导出）无需他人协助跑通 | 1 位操作者独立完成 | 第 4 周 |
| S7 | 端到端现场演示 3 分钟内完成 | 通过 | Demo Day |

**解释规则。** S3 / S4 是**可行性**结果，不是普适结论：三个人身上看到效应，支持「这个场景下检测可行」，不证明可推广，写的时候也不许写成可推广。若脑电这两项都对不上，则主目标不成立，按第八节声明，**不许拿肌电结果充数**。

## 六、范围——明确不做的事

- **不做自动决策。** 系统从不拦作业、从不判断「停」——它是镜子，不是判官。
- **不声称异常检测能减少失误。** 那需要「给反馈 vs 不给反馈」的对照实验，本研究之外。
- **不诱导失误。** 不在真实流程里人为制造错误；真实物料属于另一个在研项目。
- **不做跨操作者、跨任务比较。** 人与任务在设计上完全混淆。
- **不把状态分类成命名状态**（「疲劳」「过载」）。输出只是定位到某一步的异常标记。这不只是保守——主指标 theta/alpha 会被两个方向相反的对照推向两头，**它本来就不是一把「累」的刻度**。
- **不融合各通道成单一「状态分」。**
- **MVP 阶段不做肌电**（第九节第三次修订）。在它真正跑通前，本项目不声称有两条通道。
- **不做医学或诊断声明。** 多用户账号、云部署、移动端，都不在范围内。

## 七、利益相关者、伦理与数据合规

| 利益相关者 | 角色 | 状态 |
|---|---|---|
| 科研导师 | 科学指导，批准采集方案 | 已批准 |
| 操作者 B、C | 参与者 | 已签署知情同意；数据处置已约定 |
| 课程教学团队 | 范围与里程碑确认 | 个人方案，待确认 |
| 实验室项目组 | 提供真实流程与 SOP | 已就位 |

- **人体数据。** 三位操作者各自同意，各自只在自己执行任务时被记录。原始生理数据留在本地机器，不上传任何云服务或外部工具。
- **隐私。** 本阶段不涉及视频处理。导出数据集不含个人标识；分析与成文一律以 A / B / C 指代。
- **退出。** 任何操作者可在任何时候退出并要求删除其记录，无需理由。
- **肌电的前置条件（非阻断，且已查明）。** 表面肌电用**双极**电极对，脑电导联是**单端（带参考）**——**设备手册已查清：ADS1299 的 SRB2 是每通道独立开关位，故两者可以混搭**；只剩一块板叠加的约 10 分钟实测没做（`EEG\SHARED_DEPS.md` §6.2）。**不占用当前工期**。届时按 (a) 同一系统同采 → (b) 独立设备同步到同一时钟 → (c) 继续只做脑电 的顺序决策；注意 (c) **不再是降级**——主目标本来就只依赖脑电。
- **长期底线。** 不向 AI 工具提供任何敏感实验数据、未发表结果、凭据或参与者信息。

**风险与降级方案。**

| 风险 | 降级方案 |
|---|---|
| 主通道在真实湿实验中伪迹太大，安静段与噪声段分不开 | 先用信号质量闸门剔除坏段（复用验收内核）；再靠**同一 session 内的相对对比**——伪迹对两段同等，差分后存活。仍不可分则按第五节声明主目标未成立，如实报阴性；**不许**改用肌电结果充数 |
| 肌电与脑电无法同采 | 已从关键路径移出：MVP 与 Stage 3 不使用肌电，推迟到肌电引入时再解决（第七节） |
| （肌电阶段）间歇性任务里 MDF 下降太小 | 届时启用持续收缩校准（session 首尾各 20–30 秒等长收缩，作同 session 的相对参照）；仍为阴性则延长 session 或加大负荷——阴性就报阴性 |
| 某些周无法把采集挂到真实 session 上 | 用动作构成相同的替代练习任务顶上；该 session 在日志里标注为替代 |
| 观察到的失误极少 | 属预期；次级分析本就限定为探索性，不把关任何交付物 |
| 检测效果差 | 阴性结果是 Stage 3 的合法结果，照实报告；不阻塞软件交付物 |
| session 超出可用时间 | session 本就在每周日程里；协议上限 90 分钟 |

## 九、过程证据与 AI 使用

- **仓库历史很短。** LabPulse 仓库创建于 **2026-10-04**。此前的相关工作（最初的问题界定、更早的草稿）发生在版本控制之外，**没有可复现的提交时间戳**。缺口如实写在这里，不做粉饰。
- **AI 参与的工作有日志。** 每次产生改动的 AI 交互都记录在 `AI使用日志.md`，时间戳取 git 提交时间。AI 用于起草、实现与校验；研究问题、范围取舍与结果解释由作者本人决定。
- **三次修订（修订本身就是过程证据）。**
  1. **2026-10-12 上：方向修订。** 从「工位记录工具」改为「状态异常识别」（被试内、对本人基线）；采纳两项升级——表面肌电一度升为主通道，SOP 步骤表成为结果骨架（输出从「反推的时间线」变成「哪一步偏离」）；并定下三人被试内、白噪声阳性对照、不做诱导错误。
  2. **2026-10-12 下：主通道由肌电改回脑电。** 理由三条：(i) 原方案让**主通道**去扛第七节那个同采风险（当时尚未验证；10-11 已查清芯片层可行、只剩约 10 分钟两板实测），风险压错了位置——换脑电后最坏情况只是砍掉辅通道；(ii) 脑电的验证证据更硬：白噪声是**实验者人为开关**的负荷，而时疲劳自然发生、幅度不可控；(iii) 主题、空间与硬件都在脑电上，主目标不该锚在辅助模态上。本次只撤销「哪条通道扛主目标」，状态异常识别、SOP 定骨架、三人被试内、不诱导错误**四项全部保留**；同时把主指标写实为 **theta/alpha** 并要求**双侧**判定——两个对照会把它推向相反方向，这反过来成了「不分类」的实验依据。
  3. **2026-10-13：肌电推迟到后续阶段。** MVP 与 Stage 3 只依赖脑电，肌电在 Stage 4 前后引入。这使第七节的同采问题**不再是阻断性风险**，从关键路径彻底移出；代价是只有单模态证据，如实声明。
- **已知代价（一并记下）。** 脑电在真实作业中伪迹更重、效应量更小，每人 2+2 次 session 只够看**大效应**——所以第五节的成功标准一律按**可行性**解释，不写成显著性结论。

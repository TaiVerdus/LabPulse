## 一、问题

湿实验的质量保障**完全是事后发现**。稀释倍数算错、离心管标错，通常要到下游才暴露——几小时之后，或者永远不暴露。等失效显形时，原因已经不可恢复：没人知道是哪一步出的问题，更不知道为什么会出。

现在的流程缺三样东西：

1. **错误发现得太晚。** 一批样品报废时，真正出问题的那一步已经埋在两小时的时间线里，没有任何标记。
2. **操作者的状态从未被记录。** 人因研究普遍把认知过载和注意力衰退当作流程性作业的主要错误来源，但在真实实验室里，操作者的状态**没有任何东西在记录**。现成的两个手段都不好使：自陈（不准，而且一打断就把手上的活毁了）；录像回看（准，但没人会为了找五秒钟的失误去回看两小时素材）。
3. **真正重要的那个状态没有单一测量。** 认知负荷和注意力衰退既没有阈值，也没有金标准；而让操作者自己报告，会直接破坏他的作业节奏。（这不是放弃它的理由——本项目要测的目标状态**恰恰就是它**。我们缺的是一把能直接读数的"标准尺"，但我们有另一种东西：**可以把负荷开关握在自己手里**。把负荷人为打开和关掉，验证问题就从"测出来的值对不对"变成"同一个人的两段能不能分开"——后者答得出来，见第二节与第四节。）

实际后果：一个正在走向失误的操作者，在失误真正发生之前，收不到任何信号。

## 二、研究方向

**LabPulse 是一面镜子，不是一个判官。** 系统不替操作者判断他还能不能继续。它把操作者自己的信号、对着他自己的基线摆出来看，判断权在操作者手里。整件事的前提就是这句话：*我们很难定义「累不累」，但可以帮一个人意识到自己累了。*

所以我们不去定义、也不去测量「疲劳」这个复合概念。我们拿操作者**自己的基线**当参照，只问一个更窄、也答得出来的问题：

> **一个人的生理指标相对他自己基线的偏离——也就是「状态异常」——能不能在他还在工作时就被识别出来，并且定位到 SOP 的某一步？**

**两条互补通道，而且刻意不对称。** 每条通道各自绑一个对照来验证（见第四节），谁也不至于无凭无据：

| 通道 | 测什么 | 强在哪 | 角色 |
|---|---|---|---|
| **脑电 EEG** | 认知负荷 / 注意 | 本项目真正想测的那个状态就在这条通道上；而且**负荷可以被实验者人为开关**（纯净白噪声段，第四节对照 1），于是"它到底有没有在测东西"这件事是可以被验证的——不必依赖一把并不存在的金标准。弱点同样是真实的：真实作业中伪迹重，见第八节风险表。 | **主** |
| **肌电 EMG**（表面） | 动作执行 + **肌肉疲劳** | 有教科书级标记：表面肌电**中值频率（MDF）随持续收缩而下降**。可测、可重复，而且**在单个受试者身上就能看出趋势**。 | **辅** |

这个分工是本次的关键取舍。认知负荷是我们在乎的目标，它**没有金标准**——"负荷高不高"没有一把尺子能直接读出来；但**我们可以自己把负荷打开和关掉**，于是验证问题从"测出来的值对不对"变成"同一个人的两段能不能分开"。这跟肌电那条通道的做法是**同一套逻辑**（也是靠前后对比，而不是靠绝对刻度），区别只在于：外源白噪声是我们确知发生了的负荷，自然疲劳不是。所以主目标锚在能人为操纵的那条通道上，肌电留作辅助，如实按「探索性」报告。

**SOP 定骨架。** 不去从信号里反推时间线，而是让 SOP 步骤表直接提供时间线：每一个信号窗口都挂在已知的一步上（「稀释，第 3 步」）。于是检测器的输出不是抽象的「一段异常」，而是一句**有名字、看得懂的话——「稀释 SOP 第 3 步偏离了」**。这才是这个问题可解、结果也能向操作者解释的原因。

**主目标**
被试内识别状态异常：对每个人自己的基线比较，并定位到 SOP 时间线上。

**次级目标（仅探索性）**
观察那些「检出异常之后跟着发生了一次可记录的操作失误」的案例。因为自发错误很少，这部分只能是**产生假设的观察，不是被检验的因果结论**——见第六节。

**「状态异常」的操作定义**（在采集开始前定死，检测器才可被评判）：

> 状态异常：某条通道的指标，相对该操作者**安静作业基线**偏离超过 **X 个标准差**，并持续至少 **Y 秒**。
>
> - **脑电指标**（主）：**theta / alpha 功率比**为主指标；其余频段（delta / alpha / beta）相对本人基线的偏离**分别报告**。不合成复合指数——每引入一个复合指数，就多一层要先被验证的假设。
> - **肌电指标**（辅）：任务所动用肌群的**中值频率（MDF）**与**幅值（RMS）**。
>
> 两条通道**各自独立判定、分别报告，绝不融合成一个分数**——两者时间常数不同，证据强度也不同。
>
> ⚠️ 主指标是**双侧**的。白噪声段（唤醒 / 注意升高）与 session 后段的警觉度衰减，会把 theta/alpha **推向相反方向**。这恰恰是"不许把偏离翻译成命名状态"的实验依据（第六节）：同一个比值能朝两头偏，它就不是一个"累"的刻度。
>
> *X 与 Y 按通道在头两次基线 session 分析后定下，此后全程冻结。要求「持续」是为了不让一次眨眼或一个动作伪迹就报警。*

## 三、我们要做的东西：LabPulse

LabPulse 是一个桌面 Web 应用（Python + Streamlit，本地运行，不上云，不要账号），存在的意义就是让上面这个研究做得成。五个模块：

| # | 模块 | 做什么 |
|---|---|---|
| 1 | **采集** | 从实验室采集设备接收实时脑电与表面肌电，所有采样对齐到同一个时钟打时间戳。 |
| 2 | **SOP 时间线** | 按任务的 SOP 步骤表记录流程。这张步骤表是**整个系统的骨架**——是它把一段信号变成「有位置的结果」。步骤表用**配置文件**，每个任务一份（称量 / 稀释 / 采样），同一套代码服务三个任务。 |
| 3 | **事件标记** | 作业中一键 / 热键打标（「本步完成」、「发现失误」、自由标签）。稀释时双手都占着，任何需要打字的交互事实上不会发生。 |
| 4 | **状态异常检测** | 计算两条通道的指标（**脑电 theta/alpha 比为主**，肌电 MDF/RMS 为辅），各自与操作者本人基线比较，按冻结的 X / Y 规则标记持续偏离，并**归因到具体的 SOP 步骤**。 |
| 5 | **同步回看与导出** | SOP 步骤时间线 × 生理曲线同图；点任一标记就跳到对应信号区间；会话记录导出为结构化 CSV。 |

信号质量检查复用设备验收阶段已写好并验证过的分析内核，不重写（模块化与复用）。

**对齐要求。** SOP 时间线由人打点（分钟量级），生理信号是连续的（毫秒量级）。两者必须打在同一时钟上；**标记到信号的错位必须小于 1 秒**，否则事后两条流根本对不上。

## 四、研究设计

**参与者与任务——固定分配。**

| 操作者 | 任务 | 时段 |
|---|---|---|
| 操作者 A | 称量 | 各自独立时段 |
| 操作者 B（本人） | 稀释 | 各自独立时段 |
| 操作者 C | 采样 | 各自独立时段 |

每人**只做自己那一项任务**，不交叉。这意味着人与任务无法分离，因此**不做任何跨人或跨任务的比较**（见第六节）。每个人当作一个独立的被试内案例来分析：三个各自独立的小实验，各自带自己的基线。

**每条通道各有一个阳性对照，主通道另有第二个。**

**对照 1 —— 白噪声 → 验证主通道（脑电 / 认知负荷）。**
白噪声在固定区段打开：它叠加外源负荷，不改变任务本身，而且**由实验者开关**——我们确知它发生了。如果脑电通道**在同一个操作者身上**都分不出安静段和噪声段，那它就没在测量任何可用的东西。噪声源固定、音量固定、每次 session 用同一套硬件。（否掉音乐：音乐节奏会进入脑电频谱，污染正要测的那个频段。）

**对照 2 —— session 内时间负荷 → 主通道（脑电）的第二个对照，同时验证辅助通道（肌电）。**
session 固定 90 分钟；比较同一 session 的**前 30 分钟与后 30 分钟**。持续作业下的警觉度衰减是脑电最经典的效应之一；同一对比下肌电 MDF 的下降，则是肌肉疲劳的标记。两条通道共用这一次对比，**不额外花 session**——负荷由真实工作本身产生。

因此主通道有**两个来源不同、方向相反的对照**：一个是外源突加负荷（白噪声），一个是内源缓慢衰减（时作业）。任一个单独通过都只算弱证据；两个都能分开，才算这条通道确实在工作。这也给了一个不靠绝对刻度、只靠前后对比的验证逻辑——与第二节的取舍一致。

**校准（可选，每次 session 约 1 分钟）。** 在 session 首尾各录一次简短等长持续收缩（20–30 秒，自选力度、尽量稳住），作为同一 session 内、与任务无关的 MDF 下降参照。它是**相对**的前后对比，不是绝对力值测量。要不要做，等基线 session 出来再定——见第八节风险表。

**协议与数据量。**

| 阶段 | 每人 session 数 | 合计 | 日历 |
|---|---|---|---|
| 安静基线 | 2 | 6 | 2 周 |
| 白噪声段 | 2 | 6 | 2 周 |
| **合计** | **4** | **12 次 session** | **4 周** |

每次 session 1–2 小时，直接嵌入三位操作者**既有的每周实验日程**——不需要为本研究额外造 session。
预计产出：约 18 小时记录 ≈ **约 2000 个不重叠的 30 秒窗口**，每人自带基线。相邻窗口强相关，有效独立样本远小于这个数；真正的瓶颈是 **session 次数**，不是窗口数。

**次级（探索性）分析。** 操作失误在作业中当场记录，或事后由下游结果回填。自发错误率约每次 session 1–2 次，整个研究最多也就几十个事件。这远低于做「状态↔错误」关联检验所需，因此次级分析只作为**案例集**报告，绝不写成相关性或因果结论。

## 五、成功标准

| # | 标准 | 目标 | 验证时间 |
|---|---|---|---|
| S1 | 每位操作者两次基线 session 完成并分析 | 3/3 人 | 第 2 周 |
| S2 | X / Y 阈值**按通道**定下并记录在案（在白噪声段之前） | 冻结、成文 | 第 2 周 |
| S3 | **主通道（脑电）**：白噪声段相对该操作者安静基线出现可检出的偏移 | 3/3 人 | 第 4 周 |
| S4 | **主通道（脑电）第二对照 + 辅助通道**：session 内前 30 分钟 vs 后 30 分钟——脑电 theta/alpha 出现可检出变化；肌电 MDF 出现下降 | 12/12 次 session 算出；各通道 ≥2/3 人；肌电若为阴性则启用第四节校准备选，并如实报为阴性 | 第 4 周 |
| S5 | SOP 标记与信号时间线对齐 | 错位 < 1 秒 | 第 1 周 |
| S6 | 一次完整 session（采集 → 打标 → 回看 → 导出）无需他人协助跑通 | 1 位操作者独立完成 | 第 4 周 |
| S7 | 端到端现场演示 3 分钟内完成 | 通过 | Demo Day |

**解释规则。** S3 与 S4 是**可行性**结果，不是普适结论。三个人身上看到效应，支持的是「这个场景下检测可行」；它不证明可推广，写的时候也不许写成可推广。**主通道的降级路径**：若 S3 与 S4 里的脑电部分都对不上，则主目标不成立——此时按第八节风险表明确声明为降级，**不许拿辅助通道（肌电）的结果充当主目标的成功**。

## 六、范围——明确不做的事

- **不做自动决策。** 系统从不拦住操作者的作业，也从不判断「停」。它是镜子，不是判官（第二节）。
- **不声称异常检测能减少失误。** 那需要「给反馈 vs 不给反馈」的对照实验，本研究范围之外。
- **不诱导失误。** 不会在真实实验流程里人为制造错误；真实物料属于另一个在研项目。
- **不做跨操作者、跨任务比较。** 人与任务在设计上完全混淆（第四节）。
- **不把状态自动分类成命名状态**（如「疲劳」「过载」）。输出只是定位到某一步的异常标记，仅此而已。而且这不只是保守——第二节的主指标 theta/alpha 会被两个方向相反的对照推向两头，**它本来就不是一把「累」的刻度**。
- **不把肌电与脑电融合成单一「状态分」**（见第二节）。
- **不做医学或诊断声明。** 这不是健康设备，也不许被这样描述。
- 多用户账号、云部署、移动端，都不在范围内。

## 七、利益相关者、伦理与数据合规

| 利益相关者 | 角色 | 状态 |
|---|---|---|
| 科研导师 | 科学指导，批准采集方案 | 已批准 |
| 操作者 B、C | 参与者 | 已签署知情同意；数据处置已约定 |
| 课程教学团队 | 范围与里程碑确认 | 个人方案，待确认 |
| 实验室项目组 | 提供真实流程与 SOP | 已就位 |

- **人体数据。** 三位操作者，各自同意，各自只在自己执行任务时被记录。原始生理数据留在本地机器，不上传任何云服务或外部工具。
- **隐私。** 本阶段不涉及任何视频处理。导出数据集不含个人标识；分析与成文中一律以 A / B / C 指代。
- **退出。** 任何操作者可在任何时候退出，并要求删除其记录，无需给出理由。
- **阻断性前置条件（必须在采集开始前解决）。** 表面肌电用**双极**电极对，而脑电导联是**单端（带参考）**接法。两者能否**在同一次 session、同一台放大器上**同时采集，必须在冻结协议前对照设备手册确认。注意这一项卡住的是**辅助通道**，不是主目标——主目标（脑电）走实验室已有、并已通过验收的那套设备。可选方案，按优先级：
  (a) 同一系统上同时采两路；
  (b) 肌电走独立通道组或独立设备，同步到同一时钟；
  (c) **只做脑电**，主目标完全不变，肌电挪到后续阶段。**方案 (c) 是砍掉辅助通道的降级，必须明确声明**——不许包装成"两条通道都跑了"。
- **长期底线。** 不向 AI 工具提供任何敏感实验数据、未发表结果、凭据或参与者信息。

## 八、时间线与风险控制

| 里程碑 | 日期 | 目标状态 |
|---|---|---|
| Stage 1 | 10-13 | 本提案 + 仓库链接 |
| 基线 session | 10-13 ~ 10-26 两周 | 6 次 session，阈值 X / Y 冻结 |
| Stage 2（MVP） | 10-27 | 模块 1–5 在已录 session 上端到端跑通 |
| 白噪声段 | 10-27 ~ 11-09 两周 | 6 次 session |
| Stage 3（验证） | 11-10 | 3/3 人检测结果；下一轮修订计划 |
| Stage 4（Beta） | 12-01 | UI 打磨、真实 session 回看、可靠性过一遍 |
| Stage 5（Demo Day） | 12-08 | 端到端现场演示，3 分钟内 |

**风险与降级方案。**

| 风险 | 降级方案 |
|---|---|
| 肌电与脑电无法同采（**阻断性**） | 按第七节 (a) → (b) → (c)；方案 (c) 砍掉辅助通道，**主目标不受影响**，但必须在文中声明为降级 |
| 主通道（脑电）在真实湿实验中伪迹太大，安静段与噪声段分不开 | 先靠信号质量闸门剔除坏段（模块 5，复用验收内核）；再靠**同一 session 内的相对对比**——伪迹对两段是同等的，差分后存活。若仍不可分，则按第五节降级路径声明主目标未成立，并如实报为阴性；**不许**改用辅助通道的结果充数 |
| 辅助通道（肌电）在间歇性任务里 MDF 下降太小、看不出来 | 启用第四节持续收缩校准；若仍为阴性，则延长 session 或加大任务负荷——并把阴性结果报为阴性结果 |
| 某些周无法把采集挂到真实 session 上 | 用动作构成相同的替代练习任务顶上；该 session 在日志里标注为替代 |
| 观察到的失误极少 | 属预期；次级分析本就限定为探索性，不把关任何交付物 |
| 检测效果差 | 阴性结果是 Stage 3 的合法结果，照实报告；它不阻塞软件交付物 |
| session 超出可用时间 | session 本就在每周日程里；协议上限 90 分钟 |

## 九、过程证据与 AI 使用

- **仓库历史很短。** LabPulse 仓库创建于 **2026-10-04**。此前的相关工作（最初的问题界定、更早的草稿文档）发生在版本控制之外，因此**没有可复现的提交时间戳**。这个缺口如实写在这里，不做粉饰；AI 使用日志里也记了同一条。
- **AI 参与的工作有日志。** 每一次产生改动的 AI 交互都记录在 `AI使用日志.md`，时间戳取 git 提交时间。AI 用于起草、实现与校验；研究问题、范围取舍与结果解释由作者本人决定。
- **方向修订。** 项目方向在 **2026-10-12** 经一次设计评审后修订。原始框架是「工位记录工具」，修订后改为「状态异常识别」。同一次评审采纳了两项升级：(i) **表面肌电升为主通道**（肌肉疲劳有可测标记，认知状态没有），脑电保留为辅助通道；(ii) **SOP 步骤表成为结果的骨架**，输出从「从信号里反推的时间线」变成「哪一步偏离了」。评审同时定下另外三点：主目标为状态异常识别、三人被试内设计、白噪声阳性对照、不做诱导错误。本次修订取代此前的提案。原始框架与修订原因都记录在案（旧草稿已清出仓库，修订记录本身保留在本节与 AI 使用日志中）——课程要求每次评审提交「当前版本 + 过程证据 + 下一轮决策」，修订本身就是过程证据。
- **2026-10-12 第二次修订：主通道由肌电改回脑电。** 同日晚些时候的一次评审推翻了数小时前的取舍，理由三条：(i) 原方案让**主通道**去扛第七节那个尚未解决的阻断性技术风险（双极肌电与单端脑电能否同采），风险压错了位置——改由已通过验收的脑电设备扛主目标后，最坏情况只是砍掉辅助通道；(ii) 脑电的验证证据其实更硬：白噪声是**实验者人为开关**的负荷，确知它发生了，而时疲劳是自然发生、幅度不可控的；(iii) 领域与设备一致性——本项目的主题、空间与硬件都在脑电上，主目标不该锚在辅助模态上。

  这一次撤销的只是**「哪条通道扛主目标」**，不是 10-12 那次评审本身：状态异常识别、SOP 定步骤骨架、三人被试内设计、不做诱导错误，四项全部保留。同时把主指标写实为 **theta/alpha**（此前只写"频段功率比"三个字），并要求它**双侧**判定——因为两个对照会把它推向相反方向，这一点反过来成了「不把偏离翻译成命名状态」的实验依据。

  ⚠️ 代价一并记下：脑电在真实作业中伪迹更重、效应量更小，每人 2+2 次 session 只够看**大效应**。因此本节的成功标准（第五节）一律按**可行性**解释，不许写成显著性结论。

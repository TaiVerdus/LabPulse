## 1. 产品概述

LabPulse 是一个**桌面网页应用**：在 Windows 笔记本本地运行、浏览器中使用，不需要账号、不依赖网络，数据全部留在机器里，靠一个一键启动脚本（`.bat`）打开。一句话概括：**"实验操作的自带黑匣子记录仪"**。

## 2. 最终产品模块清单

## 3. 用户故事

**US-1 —— 可信的导入。** *作为实验操作者，我想导入一段脑电记录后立刻知道质量是否可信，这样我就不必浪费一场会话去分析垃圾数据。*  
验收标准：文件选择器支持 EDF/BDF/CSV；质量面板逐通道显示噪声底（μV）、平直通道标记、工频比值、尖峰计数（由 `acceptance_check` 内核计算）；不达标通道高亮；给出总判读（OK / 需检查 / 坏）。

**US-2 —— 一键打标。** *作为双手都占着的操作者，我想用一次点击或热键给事件打标，这样记录从不打断流程。*  
验收标准：可配置按钮（标签 + 颜色）；时间戳相对脑电时钟误差 < 1 秒；标记实时列出；事后可编辑；单次会话 ≥ 10 个标记无性能损失。

**US-3 —— 同步回看。** *作为操作者，我想把操作时间线和脑电频段能量曲线放在一张同步图上，这样我能从任意事件跳到它周围的大脑状态。*  
验收标准：事件标记渲染为时间线图上的竖线；点击标记缩放到 ±30 秒；能量曲线用 Welch 法（MNE-Python）计算，4 秒窗、50% 重叠。

**US-4 —— 结构化导出。** *作为研究者，我想把结构化会话日志导出为 CSV，这样它能直接喂给后续分析。*  
验收标准：CSV 字段 = event_id、时间戳（ISO + 距开始秒数）、label、通道质量摘要、源文件名；样例能在 Excel/pandas 中干净打开。

**US-5 —— 我自己的设备。** *作为研究者，我想导入一段用自己 16 通道设备在真实湿实验中录的会话，这样工具才能服务我的实际研究。*  
验收标准：设备导出的 EDF/CSV 无格式错误地导入；通道名映射到 10–20 导联体系。

**US-6 —— 实时模式。** *作为研究者，我想让时间线随实时数据流持续更新，这样我能边干活边看状态演变。*  
验收标准：LSL 流（LSL 不可用时用文件回放）持续刷新图表；α/θ 指标每几秒刷新；连续运行 5 分钟无中断。

**US-7 —— 会话管理。** *作为研究者，我想在几小时后重新打开旧会话补标、改标，这样日志才准确。*  
验收标准：历史会话列表显示时间与文件名；重新打开恢复全部标记；修改能写入导出的 CSV。

**US-8 —— 演示就绪。** *作为要在演示日展示的学生，我想让应用在现场观众面前不出岔子。*  
验收标准：一键启动脚本能从干净状态启动应用；遇到异常显示空状态/友好错误提示而非报错堆栈；端到端演示（导入→打标→回看→导出）在 3 分钟内完成。

## 4. 技术假设与架构

- **语言**：只用 Python（与同修的编程课一致——一条学习曲线）
- **应用框架**：Streamlit —— 本地桌面网页应用，浏览器中使用，可直接演示
- **脑电处理**：MNE-Python（滤波、Welch 功率谱、导联体系）；NumPy/pandas
- **复用**：信号质量模块从 `acceptance_check.py` 导入（课程目标：模块化与复用）；不复制粘贴第三方代码
- **实时流**：pylsl 配合供应商提供的 OpenBCI_LSL 桥；以文件模拟实时作为兜底
- **硬件（仅模块 5–6）**：ExpandableBCI 16 通道（ADS1299），250 Hz —— 核心功能完全不需要
- **交付形态**：一键 `.bat` 启动脚本；数据全部本地存储（隐私 + 离线可用）
- **版本控制**：从第一天起用 Git；按功能/修复写有意义的提交信息
- **分层架构**（接口与实现分离）：
  1. `data/` —— 文件解析、导联映射（文件 → MNE Raw 对象）
  2. `analysis/` —— 质量检查、频段能量（纯函数，可单测，不含界面代码）
  3. `session/` —— 事件打标、时间戳对齐、持久化、导出（状态管理）
  4. `ui/` —— Streamlit 页面，只调用下层；界面代码里不写信号数学
- **运行环境**：Windows 11 笔记本；隔离的 Python venv；无需管理员权限

## 5. 测试计划（关键路径）

| #  | 关键路径  | 测试                                  | 证据           |
| -- | ----- | ----------------------------------- | ------------ |
| T1 | 导入    | 导入演示用到的每个公开数据集文件格式                  | 导入日志 + 截图    |
| T2 | 质量标记  | 用一段故意破坏通道的已知坏记录，必须被标记               | 面板前后对比截图     |
| T3 | 时间戳对齐 | 在合成会话中于已知时刻打标；导出须匹配在 1 秒内           | 导出 CSV vs 真值 |
| T4 | 导出完整性 | 导出的 CSV 能在 pandas 重新打开；字段齐全、无整列 NaN | 测试脚本输出       |
| T5 | 持久化   | 24 小时后重新打开会话，标记与修改完好                | 截图 + CSV 对比  |
| T6 | 实时稳定性 | 实时模式连续运行 5 分钟无中断、无漂移                | 运行时日志        |
| T7 | 演示健壮性 | 从干净状态计时跑一遍端到端演示                     | 计时日志 + 录屏    |
| T8 | 回归    | 每次验证修复后重跑 T1–T7                     | 每次迭代的测试日志    |

## 6. 明确不做的（范围外）

自动认知状态分类（研究问题，不是课程交付物）· 多用户/账号 · 云端部署 · 实时反馈或干预 · 手机 App。

# LabPulse：无设备阶段操作手册

2026-11-05｜机械臂与 Jarvis 延后；本次完成离线研究软件准备

## 在这台电脑上直接使用

当前工作区根目录有 `scripts`、`offline`、`reports`、本地 `.venv` 和公开数据缓存。**运行入口在本工作区，不是 D 盘原有的 run_lsl.bat。** 没改动 D 盘科研算法主本，也没有把它复制过来。

1. 双击 `scripts/run_offline.bat`。先检查依赖，再读取本地公开 ErrP 数据、训练固定基线，评价保留试次，然后回放前20条预测。全程无需设备，不访问网络。
2. 阅读 `reports/offline/验证结果.md` 和 `metrics.json`。命令窗口里“未触发预警”不等于真实没有错误；误报和漏报以完整计数为准。
3. 双击 `scripts/check_offline.bat`。它运行依赖检查、逻辑测试和本机合成 LSL 联调。Windows 如提示网络权限，LSL 使用的是本机/局域网发现；不要据此判断需要外网。模拟失败时看 `local_runs/sim_check/receiver.log`，不要标记通过。
4. 可运行 `scripts/practice_screen.bat` 熟悉20次屏幕任务。屏幕先给目标方向，再给系统方向，结果消失后选出错/正常/不确定。**这是练习，不采 EEG、不预测、不发送 Jarvis。** 记录放在 `local_runs/practice-*`。其试次安排和 GUI 交互仍需人工体验；现只做了日程与语法检查，不当作正式实验协议或验证结果。

若出现报错，保留完整窗口。第一次依赖检查已由代理执行；本地安装包已缓存。不要把本机的 `.venv` 直接搬到其他电脑。

## 换电脑或重新安装

建议 Windows x64、Python 3.13、基础 Python 可运行 pip。先克隆包含本工具的 GitHub 分支，再运行 `scripts/setup_offline.bat`。存在本地 wheelhouse 时使用 `--no-index` 安装，否则需联网。数据通过 `.venv\Scripts\python.exe -m offline.fetch` 获取一次。本机缓存安装包和匿名公开数据均不重复提交 GitHub；仓库提供固定来源、长度、SHA256与重建命令。不要假定 git clone 会带回数据或环境。

等效命令（在仓库根目录 PowerShell 运行）：

```powershell
.\.venv\Scripts\python.exe -X utf8 -m offline.health
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -X utf8 -m offline.pipeline
.\.venv\Scripts\python.exe -X utf8 -m offline.replay --limit 20
.\.venv\Scripts\python.exe -X utf8 -m offline.selftest
.\.venv\Scripts\python.exe -X utf8 -m offline.screen --dry-run
```

## 有设备后只做剩下的联调

先沿用已能采集的 AP、打开 GUI → Networking → LSL → TimeSeriesRaw，记下 Name 和 Type。新接收器要求16通道、类型 EEG、规则采样；不是这一配置时先核对界面，不要为了通过检查伪造元数据。

```powershell
.\.venv\Scripts\python.exe -X utf8 -m offline.stream list
.\.venv\Scripts\python.exe -X utf8 -m offline.stream capture --name "填实际流名称" --seconds 60 --output local_runs/device_first
```

第二条为**未实机验证的操作命令**。不要使用默认的 SIM 名称或加 `--simulate` 验收真实设备。独立 LSL Marker 流只有确实存在时才加 `--marker-name "实际名称"`；GUI Marker 是否落盘、是否另发 LSL 要分别检查。

接收器有墙钟超时，断流不会无限等。保存采样时间戳、原始通道、流 XML、独立标记与摘要。缺口检查是启发式；没有设备序号不能得出“无丢包”。没有物理校准不能得出“毫秒级同步”。本接收器也不把设备数据自动送入公开27通道模型。

## 正式采集前仍需要决定

屏幕练习不替代正式范式。需要确认目标事件、异常定义、真实可感知起点、主观反馈时机、参考与通道位置、动作/眼动控制、重复会话安排。先做本人静止观察，动手操作留待基线验证。正式试次数不是20次练习的数字；应依据先导质量、预期不确定性和可用时长决定，不做样本量保证。按完整会话/块拆训练与测试，测试前冻结配置；同一个人的多试次不能宣称是多名独立参与者。
